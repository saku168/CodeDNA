# CodeDNA

**Visualize your codebase. Understand your architecture.**

CodeDNA is an open-source project exploring clearer ways to understand a software project’s structure and architecture.

> **Project status:** Early development. Features, supported languages, and setup instructions will be documented here as they become available. This README intentionally does not claim functionality that has not yet been verified.

## Why CodeDNA?

As a codebase grows, it can become harder to see how its files and components fit together. CodeDNA aims to make that structure easier to explore and understand.

## Project goals

The current direction for CodeDNA is to work toward:

- **Codebase overview** — make a project’s structure easier to understand.
- **Architecture visualization** — present relationships between parts of a codebase.
- **Clear navigation** — help developers explore unfamiliar projects.
- **Useful documentation** — explain what the tool can do and how to use it.

These are project goals, not a claim that every feature is already implemented.
